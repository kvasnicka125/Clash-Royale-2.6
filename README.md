# Clash-Royale-2.6
## Clash Royale 2.6 Hog Cycle - AI Web Project

Tento projekt je moderní vícestránkový web zaměřený na jeden z nejpopulárnějších a nejznámějších balíčků ve hře Clash Royale – 2.6 Hog Cycle.

Web byl vytvořen v rámci školního/studijního úkolu zaměřeného na efektivní komunikaci s umělou inteligencí (prompting), generování funkčního kódu, verzování pomocí Git/GitHubu a publikaci přes GitHub Pages.

## Obsah a struktura webu

Web se skládá ze tří navzájem propojených HTML stránek a jednoho sdíleného CSS souboru:

index.html (Hlavní stránka): Úvod do balíčku 2.6 Hog Cycle, princip fungování, výhody strategie a ukázka ze hry.

karty.html (Složení balíčku): Detailní seznam a rozbor všech 8 karet (Hog Rider, Cannon, Musketeer, Ice Golem, Skeletons, Ice Spirit, Fireball, The Log).

zdroje.html (Zdroje a AI): Seznam použitých zdrojů a podrobná citace použité AI včetně konkrétních promptů.

style.css: Externí CSS soubor zajišťující jednotný tmavý herní design, responzivitu a rozvržení prvků (CSS Grid a Flexbox).
